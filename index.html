Todo PWA

Žádný soubor

Začněte otevřením nebo vytvořením markdown souboru

Data se ukládají lokálně do .md souboru na vašem PC. Smazané úkoly zůstávají v souboru jako komentáře.

Pro přímý zápis do souboru použijte Chrome/Edge přes https:// nebo localhost. Na HTTP funguje režim s importem a stažením .md.

Aktivní úkol

—

Časovač 00:00:00
Pomodoro 0
Relace 25:00
Fáze Práce

Piš odrážky — hotové označ `- [x]`. Ukládá se automaticky.

Úkoly

Jedna odrážka = úkol, odsazené odrážky = podúkoly.
